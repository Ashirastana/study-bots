# Учебные боты (испанский, ИИ, турецкий) — запуск 24/7 на хостинге

`main.py` запускает всех ботов из `bots.list` в одном процессе (экономия памяти на
бесплатном тарифе 256 МБ). У каждого бота свои настройки `<бот>.env` (без секретов),
свой токен и своя база SQLite в `/data/<бот>/bot.db`. Упал один — перезапускается только он.

## Переменные окружения (секреты) на хостинге
- `ES_BOT_TOKEN` — токен испанского бота (или поле «Telegram bot token» = `TELEGRAM_BOT_TOKEN`)
- `AI_BOT_TOKEN` — токен ИИ-бота
- `TR_BOT_TOKEN` — токен турецкого бота
- `GROQ_API_KEY` — ключ Groq (общий)

Команда запуска: `python main.py`. Порты не нужны (polling).

## Добавить ещё бота
1. Файл `<имя>.env` по образцу `bot_ii.env`, строка `<имя> <ПРЕФИКС>` в `bots.list`.
2. Переменная `<ПРЕФИКС>_BOT_TOKEN` на хостинге. Каждый бот добавляет ~10–20 МБ памяти.

## Важно
Один токен нельзя опрашивать из двух мест: перед запуском на хостинге остановите ботов на Mac
(`bash stop_mac.sh` в папке student-bots).

## Турецкий бот (`turkbot.py`, модули `tr_*`)
Интенсив с нуля, 1,5–2 часа в день: 30 слов в день (словарь `tr_words_*.py`, ~1340 слов, казахские подсказки),
34 урока грамматики (`tr_lessons.py`, порядок тем как у Д. Петрова, объяснения свои), программа на 16 недель
(`tr_plan.py`), игры (`tr_games.py`: гармония гласных и спряжение строятся по правилам, есть тесты),
ИИ-учитель (`tr_ai.py`). Приглашение: `t.me/<бот>?start=turkce2026`.

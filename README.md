# Учебные боты на Northflank (24/7)

Один сервис Northflank запускает всех ботов из `bots.list`. Каждый бот — отдельный процесс
под supervisord (упал один — перезапускается только он), со своей папкой данных `/data/<бот>/`,
своей базой SQLite и своими настройками `<бот>.env` (без секретов).

## Настройка сервиса на Northflank
- Сборка: Dockerfile из корня репозитория.
- Постоянный диск (Volume), путь монтирования: `/data`.
- Секреты (Environment → Secrets):
  - `ES_BOT_TOKEN` — токен испанского бота
  - `AI_BOT_TOKEN` — токен ИИ-бота
  - `GROQ_API_KEY` — ключ Groq (общий)
- Порты не нужны (боты работают через polling).

## Как добавить ещё бота
1. Файл `<имя>.env` (по образцу `bot_ii.env`), строка `<имя> <ПРЕФИКС>` в `bots.list`.
2. Секрет `<ПРЕФИКС>_BOT_TOKEN` в Northflank. Push в репозиторий → Northflank пересоберёт.

## Перенос с Mac
Базы учеников (`bot.db`) в репозиторий не кладутся. Если файл `seed/<бот>.db` есть при сборке,
он копируется на диск только при первом запуске (если базы там ещё нет).
Перед запуском на сервере ботов на Mac нужно остановить (`bash stop_mac.sh`),
иначе Telegram выдаст конфликт: один токен нельзя опрашивать из двух мест.
